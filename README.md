# student-marks-management-system
A menu-driven Python app to add, search and rank student marks, with data saved permanently in a text file.
Student Marks Management System

A application written in core Python that manages student results for five subjects (Maths, Physics, Chemistry, Python, Electrical). It calculates each student's total and percentage, lets you search by roll number, finds the class topper, and stores all records in marks_data.txt so data is kept between runs.

__Features__

- Add a student with roll number, name and marks


- Automatic total and percentage calculation


- Display all records or search by roll number


- Show the class topper


- Duplicate roll number check


- Persistent storage using file handling


__Concepts used:__


➔ Tuple, list, dictionary, functions, loops, conditionals, file handling, exception handling

__How to run:__

```python Marks_System.py```
